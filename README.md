# 📚 Book Store Sales Analysis using SQL

## 📌 Project Overview

This project is a SQL Data Analytics project focused on analyzing book store sales data using three main datasets:

- Books
- Customers
- Orders

The project uses SQL queries to analyze book sales, customer orders, book prices, authors, and customer spending.

## 🎯 Project Objectives

The main objectives of this project are:

- Retrieve the total number of books sold for each genre
- Find the average price of books in the Fantasy genre
- List customers who have placed at least 2 orders
- Find the most frequently ordered book
- Retrieve the total quantity of books sold by each author
- List the cities where customers who spent over $30 are located
- Find the customer who spent the most on orders

## 🛠️ Tools & Technologies

- GROUP BY

- Data Analysis

## 📊 Analysis Performed

### 1. Books Sold by Genre
Calculated the total number of books sold for each genre.

### 2. Fantasy Book Price Analysis
Calculated the average price of books belonging to the Fantasy genre.

### 3. Customer Order Analysis
Identified customers who have placed at least 2 orders.

### 4. Most Frequently Ordered Book
Identified the book that was ordered most frequently.

### 5. Author Sales Analysis
Calculated the total quantity of books sold by each author.

### 6. Customer City Analysis
Identified the cities where customers who spent more than $30 are located.

### 7. Highest-Spending Customer
Identified the customer who spent the most on orders.
